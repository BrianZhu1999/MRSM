# Numerical tables

These CSV files supply the free-field comparison panels:

- `experiment_results_20260331_204711.csv`: nRMSE and Pearson correlation by observation rate and channel.
- `baselines_comparison_20260331_213441.csv`: per-trial and aggregate errors for regular 2–6× downsampling.

Run `notebooks/free_field/source_figures.ipynb` to reproduce the stored plotting procedure. See `docs/cases.md` for the original observation-rate subset and upper-outlier filtering. The CSV files retain their recorded rows and values.
